# Design-and-Analysis-of-Algorithms

Contains the laboratory assignments for the Design and Analysis of Algorithms (DAA) Laboratory with problem implementations in C++, algorithmic techniques, and verified execution outputs.

---

## Index of Assignments

| Assignment | Topic / Problem Statement | Algorithm / Paradigm | Files |
| :--- | :--- | :--- | :--- |
| **Assignment 1** | Sorting Customer E-commerce Orders by Timestamp | Merge Sort (Divide & Conquer) | `assignment-1.cpp`, `output.png` |
| **Assignment 2** | Automobile Price Sorting (Highest to Lowest) | Quick Sort (Divide & Conquer) | `assignment-2.cpp`, `output2.png` |
| **Assignment 3** | Emergency Relief Cargo Distribution with Priority | Fractional Knapsack (Greedy) | `assignment-3.cpp`, `o1.png`, `o2.png` |
| **Assignment 4** | Emergency Ambulance Routing to Nearest Hospital | Dijkstra's Algorithm (Greedy) | `assignment-4.cpp`, `O1.png`, `O2.png` |
| **Assignment 5** | Optimal Routing with Dynamic Cost Updates | Multistage Graph (Dynamic Programming) | `assignment-5.cpp`, `O5.png` |
| **Assignment 6** | Multi-Truck Cargo Utility Optimization | 0/1 Knapsack (Dynamic Programming) | `assignment6.cpp`, `O6.png` |
| **Assignment 7** | Examination Timetable Scheduling with Room Allocation | Graph Coloring (Greedy) | `assignment7.cpp`, `O7.png` |
| **Assignment 8** | Traveling Salesperson Problem (TSP) | Branch and Bound (Cost Matrix Reduction) | `assignment8.cpp`, `O8.png` |

## Compilation and Execution

All programs are implemented in standard C++ and can be compiled using `g++`:

```bash
# Example: Compiling and running Assignment 1
cd Assignment-1
g++ assignment-1.cpp -o assignment-1
./assignment-1
```
